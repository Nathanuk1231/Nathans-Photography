# Nathan Lloyd Photography

My photography portfolio (NL Visuals). A dark, animated one-page site showing my landscape, nature, wildlife, urban and creative photography, shot on a Nikon D3200.

**What's on it:** a hero slideshow, a filterable photo gallery with a full-screen viewer, a featured sideways-scroll section, an About section and a contact form.

**Built with:** plain HTML, CSS and JavaScript, plus GSAP for the animations. Photos load from Supabase.
