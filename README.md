# Nathan Lloyd — Photography (v2)

A more restrained, editorial photography portfolio. Plain HTML, CSS and JavaScript; no build step.

## What's changed
- Less template-like: simpler navigation, fewer decorative effects, more editorial typography and an asymmetrical image layout.
- Quieter palette: near-black, warm off-white and a restrained blue accent.
- More natural copy, without invented awards, clients, availability claims or fake contact details.
- Gentle GSAP reveals and image movement, with reduced-motion support.
- Responsive gallery filters and keyboard-accessible lightbox.
- Instagram link and current camera kit included.

## Before publishing
The Unsplash images are temporary examples, not Nathan's photographs. Replace each image URL in `index.html` with your own image files before launch. Ideally create an `images` folder and use paths such as `images/quiet-water.jpg`. Update the captions and alt text to match the actual photos.

## Preview
Open `index.html` in a browser. Internet is required for Google Fonts, GSAP and the temporary remote images.

## GitHub Pages
Upload `index.html`, `styles.css`, `app.js` and this README into the root of a repository. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/(root)`. GitHub will show the published URL there.
